# MarketNLP

Financial sentiment classification with a TF-IDF + Logistic Regression baseline and pretrained FinBERT. Both models use the same cleaned test texts and the same evaluation code. The baseline is trained here; FinBERT is used for inference only.

## Results at a glance

| Model | Accuracy | Macro F1 |
| --- | ---: | ---: |
| TF-IDF + Logistic Regression | **0.8043** | **0.6984** |
| FinBERT, no adaptation | 0.7139 | 0.6584 |

The baseline performs better overall on this split, while FinBERT recovers more negative examples. These results compare an in-domain trained baseline with transfer inference, not model architectures under equal training conditions.

## Approach

```text
financial tweets → remove URLs, clean whitespace, deduplicate
                → TF-IDF + Logistic Regression (fit on train)
                → pretrained FinBERT (no fine-tuning)
                → accuracy, macro F1, per-class report
```

Data comes from [Twitter Financial News Sentiment](https://huggingface.co/datasets/zeroshot/twitter-financial-news-sentiment), an English financial tweet dataset published under MIT. The source files at the pinned revision contain 9,543 training and 2,388 validation rows. This project uses the published validation partition as its final test, with no parameter tuning on it.

After URL removal and case-insensitive deduplication, **9,431 training / 2,345 test texts** remain. Conflicting annotations within a partition are dropped; test texts also present in cleaned training data are removed. There is no new random split. Source labels bearish/bullish/neutral are mapped to negative/positive/neutral, an approximation between market direction and sentiment.

The baseline fits word unigram/bigram TF-IDF and Logistic Regression inside a scikit-learn pipeline, so vocabulary and IDF see training text only. Parameters are fixed: `min_df=2`, sublinear TF, `C=1`, seed 42; no hyperparameter search.

[ProsusAI/finbert](https://huggingface.co/ProsusAI/finbert) was pretrained and sentiment-fine-tuned by its authors, including on Financial PhraseBank. That is why this evaluation does not use a new split of PhraseBank. Predictions are mapped through the model's actual `id2label` configuration. Inference uses batches, `eval()` and disabled gradients, with truncation at 512 tokens.

## Detailed results

The baseline performs better overall on this split. FinBERT has higher negative-class recall (0.749 versus 0.426), but lower precision for that class. Neutral texts make up 65.4% of the test set, so accuracy alone hides minority-class errors.

These are results for an in-domain trained baseline versus transfer inference, not a controlled comparison of model architectures. Dataset and model revisions are fixed in code. [Saved results](results/model_comparison.json) are generated by the scripts; the individual model JSON files also contain class reports, confusion matrices, data hashes, settings and library versions. The comparison rejects results from different prepared data.

## Run

Python 3.11+; run from the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
python scripts/prepare_data.py
python scripts/train_baseline.py
python scripts/run_finbert.py
python scripts/compare_models.py
```

The first run downloads the data and model from Hugging Face. Data, caches and the virtual environment are excluded from Git; only small result JSON files are retained. No API key is required. `pyproject.toml` defines the dependencies and installs `src/marketnlp`, without `PYTHONPATH` changes.

FinBERT selects CUDA, then Apple MPS, then CPU. Use `python scripts/run_finbert.py --device cpu --batch-size 16` to force CPU inference. The recorded run used Python 3.13.5 and MPS; exact library versions are saved with the results. Tests use a tiny fake model and do not download FinBERT.

## Limitations

- One English tweet dataset and one fixed split; results do not establish performance on filings, other languages or future market news.
- Deduplication removes matching normalized text, not all paraphrases or related events. The published split is not a verified temporal or company-level holdout.
- Bearish/bullish labels are not identical to FinBERT's negative/positive sentiment labels, and upstream annotation details are limited.
- The baseline learns from this dataset; FinBERT does not. Avoid interpreting the gap as a general advantage of classical NLP over transformers. Complete pretraining-data overlap cannot be ruled out.
- A sentiment label is not a return forecast or a trading signal. Numeric results can vary with library versions and inference hardware.
